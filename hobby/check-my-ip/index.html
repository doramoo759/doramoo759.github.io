내 IP 주소가 궁금할 때 브라우저에서 **공인 IP(외부 아이피)**를 바로 확인하는 무료 도구입니다. 현재 연결의 IPv4·IPv6 주소, 통신사·ASN, 시간대와 IP 위치 지도를 조회하고 주소를 복사할 수 있습니다.

페이지를 열면 현재 네트워크를 자동 조회합니다. VPN을 켜거나 와이파이·모바일 데이터를 바꾼 뒤 다시 조회를 누르면 변경된 IP를 확인할 수 있습니다.

내 IP 주소 확인 방법

  1. 위 조회 도구에서 공인 IP 주소를 확인합니다. 별도 프로그램을 설치하지 않아도 됩니다.
  2. IP 주소 복사를 누르면 표시된 주소를 클립보드로 복사할 수 있습니다.
  3. 네트워크나 VPN 연결을 바꾼 뒤 다시 조회를 누르면 현재 연결을 다시 확인합니다.
  4. 즐겨찾기 추가를 누르면 PC·모바일에 맞는 저장 방법을 안내합니다. 자주 확인할 때 현재 페이지를 북마크로 저장해두면 편리합니다.
  5. 위도·경도가 제공되면 지도에서 대략적인 위치를 봅니다. 세계 지도와 내 위치로 버튼으로 표시 범위를 바꿀 수 있습니다.

공인 IP 조회 결과와 네트워크 정보 읽기

  • 공인 IP는 인터넷에서 보이는 현재 연결의 주소입니다. 같은 공유기를 사용하는 기기들은 같은 IPv4 주소를 공유할 수 있습니다.
  • 네트워크 운영 기관은 IP 대역을 운영하는 통신사나 기관입니다. VPN을 사용하면 VPN 출구의 IP와 네트워크가 표시될 수 있습니다.
  • 위치 정보는 IP 기반 추정입니다. 실제 위치, GPS 좌표나 정확한 집 주소를 의미하지 않으며, 일부 정보는 제공되지 않을 수 있습니다. 위도·경도가 있으면 국가·해안선 지도에 추정 위치를 표시합니다.
  • HTTP·TLS 정보는 이 브라우저와 API 사이의 연결 정보입니다. 브라우저나 접속 환경에 따라 달라집니다.

공인 IP와 사설 IP는 무엇이 다를까?

기기의 192.168.x.x, 10.x.x.x 같은 주소는 보통 내부망에서 사용하는 사설 IP입니다. 이 페이지는 브라우저의 요청이 인터넷에 나갈 때 사용하는 공인 IP를 보여줍니다. IPv6 환경에서는 IPv6 주소가 표시될 수 있습니다.

Windows에서 명령 프롬프트의 ipconfig로 확인하는 어댑터 주소와 이 페이지의 외부 IP가 다를 수 있습니다. Microsoft의 ipconfig 안내는 기기의 IP·서브넷·기본 게이트웨이 확인 방법을 설명합니다.

내 IP 확인에 관한 자주 묻는 질문

IP 주소 확인은 무료인가요?

이 페이지의 IP 조회와 지도 보기는 무료이며 회원가입이나 별도 앱 설치가 필요하지 않습니다. IP 주소를 확인하려면 브라우저에서 JavaScript를 사용할 수 있어야 합니다.

컴퓨터와 휴대폰의 공인 IP가 같을 수 있나요?

두 기기가 같은 공유기의 와이파이를 사용하고 같은 IPv4 연결로 인터넷에 나간다면 같은 공인 IP가 표시될 수 있습니다. 휴대폰을 모바일 데이터로 전환하거나 VPN을 사용하면 다른 IP가 표시될 수 있습니다.

IP 위치 지도와 실제 위치가 다른 이유는 무엇인가요?

IP 위치는 네트워크 대역에 연결된 지리 정보를 기반으로 추정합니다. 통신사나 VPN 출구의 위치가 표시될 수 있으며 실제 집 주소나 GPS 위치를 의미하지 않습니다. 지도는 국가·해안선을 보여주는 개략도입니다.

IPv4와 IPv6를 동시에 확인할 수 있나요?

이 도구는 현재 API 요청에 사용된 주소를 표시하므로 IPv4 또는 IPv6 중 하나가 나옵니다. 점으로 구분한 숫자 주소는 IPv4, 콜론을 포함한 주소는 IPv6입니다. 한 번의 조회로 두 주소를 모두 확인하는 기능은 제공하지 않습니다.

VPN을 켜면 내 IP가 바뀌나요?

브라우저의 요청이 VPN을 통해 나가면 VPN 출구 IP가 표시될 수 있습니다. VPN 연결 전후에 다시 조회해서 비교하세요. 분할 터널링 등 설정에 따라 브라우저 요청이 VPN을 사용하지 않을 수도 있습니다.

공유기를 재부팅하면 공인 IP가 바뀌나요?

바뀔 수 있지만 항상 바뀌는 것은 아닙니다. 고정 IP 사용 여부와 통신사의 주소 할당 방식에 따라 이전 IP를 다시 받을 수도 있습니다. 네트워크를 다시 연결한 뒤 재조회해서 확인하세요.

다른 사람의 IP나 정확한 주소도 조회할 수 있나요?

이 페이지는 현재 방문자의 연결 정보를 확인하는 도구입니다. 임의의 IP를 입력해 다른 사람의 위치를 찾는 기능은 없으며, IP만으로 정확한 개인 주소를 알 수 있는 도구도 아닙니다.

IP 조회가 안 되면 어떻게 하나요?

인터넷 연결과 브라우저의 JavaScript 설정을 확인하고 다시 조회를 눌러보세요. 응답이 지연되거나 API에 접근할 수 없으면 오류 안내가 표시됩니다. 일부 위치·네트워크 정보가 제공되지 않으면 해당 항목만 ‘정보 없음’으로 나옵니다.
