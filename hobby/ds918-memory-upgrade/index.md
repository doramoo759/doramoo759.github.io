# 시놀로지 DS918+ 메모리 16GB 업그레이드 후기와 장착 방법

date: 2019-11-02

> DS918+에 Crucial CT2K102464BF186D 8GB 두 개를 장착한 사용기. 공식 최대 8GB와 개인의 16GB 구성을 구분하고 장착, DSM 용량 확인, 메모리 검사와 원복 방법을 정리했다.


DS918+를 사고 메모리를 늘리려고 알아봤다. 아무 메모리나 사서 꽂으면 되는 것은 아니어서 규격과 모델을 찾아보고 Crucial 메모리를 골랐다. 처음에는 8GB 하나만 사려고 했는데, 해외에서 오는 김에 아예 세트로 주문했다.

8GB 두 개로 구성하니 DSM에서 합계 16GB로 인식됐다. 사용하면서 체감상 빠릿해진 느낌도 있어 만족하고 있다. 다만 **DS918+의 공식 확장 용량은 최대 8GB**다. 내가 쓰는 16GB 구성과 제조사가 지원하는 구성은 구분해서 볼 필요가 있다.

## 구입한 메모리와 구성

내가 고른 모델은 **CT2K102464BF186D**다. 아마존에서 16GB 키트, 즉 8GB 두 개 묶음으로 주문했다.

| 항목 | 구성 |
| --- | --- |
| NAS | Synology DS918+ |
| 기존 메모리 | Synology 4GB |
| 구입한 모델 | Crucial CT2K102464BF186D |
| 새 구성 | 8GB × 2, 합계 16GB |
| 메모리 규격 | DDR3L, 1866 MT/s, PC3-14900 |
| 형태 | Unbuffered SO-DIMM, 204핀 |

![아마존 주문 화면의 16GB 키트와 8GB 두 개 옵션을 보존한 이미지](/images/server/blog-nas/ds918-memory-upgrade/memory-order-alpha-v3.webp)

위 화면에서는 16GB 키트를 선택한 것을 확인할 수 있다. 상품 대표 사진만으로 실물 모듈의 품번까지 확인되는 것은 아니다. 모델명과 주문 옵션을 같이 확인하는 편이 좋다. 상품 제목이나 검색어가 비슷해도 용량·동작 속도·키트 구성이 다를 수 있다. 같은 이름의 판매 페이지가 보인다고 이 글과 같은 물건이라고 생각하지 말고, 선택한 옵션과 받아 본 모듈의 품번까지 대조해야 한다.

## 공식 최대 8GB와 내가 쓰는 16GB는 다르다

Synology의 [DS918+ 데이터시트](https://global.download.synology.com/download/Document/Hardware/DataSheet/DiskStation/18-year/DS918%2B/enu/Synology_DS918_Plus_Data_Sheet_enu.pdf)에는 기본 메모리가 4GB DDR3L SO-DIMM이며 최대 8GB까지 확장할 수 있다고 적혀 있다. [제품 발표 자료](https://www.synology.com/en-uk/company/news/article/Synology_XS_Plus_Value_series)에도 DS918+의 확장 용량은 8GB로 안내되어 있다.

따라서 8GB 두 개로 16GB를 만드는 것은 공식 범위를 넘어선 구성이다. 내 DS918+에서 인식되고 사용 중 문제가 없었다고 해서 모든 DS918+나 같은 규격의 다른 메모리까지 호환된다고 보장할 수는 없다.

[하드웨어 설치 가이드](https://global.download.synology.com/download/Document/Hardware/HIG/DiskStation/18-year/DS918%2B/enu/Syno_QIG_DS918_Plus_enu.pdf)는 기본 메모리를 제거하지 말라고 안내하며, 비정품 사용 시 보증·기술 지원에도 제한을 둔다. 기존 4GB를 교체하는 내 구성은 공식 추가 장착 방식과 다르다.

## 메모리 슬롯과 장착할 때 확인할 것

메모리 슬롯은 전면 트레이 네 개를 빼면 본체 안쪽에서 보인다. 바닥의 M.2 SSD 슬롯과는 다르다. [설치 가이드 8~9쪽](https://global.download.synology.com/download/Document/Hardware/HIG/DiskStation/18-year/DS918%2B/enu/Syno_QIG_DS918_Plus_enu.pdf)에서 그림을 확인할 수 있다.

1. 중요한 데이터의 백업을 확인하고 DSM에서 정상 종료한다.
2. 전원이 꺼진 뒤 전원선과 연결된 케이블을 분리한다.
3. 드라이브 트레이를 빼고 순서를 유지해 둔다.
4. 메모리 가장자리를 잡고 금색 접점의 홈과 슬롯 방향을 맞춘다.
5. 슬롯에 끝까지 넣은 뒤 적당한 힘으로 눌러 고정한다. 잘 들어가지 않으면 방향과 걸쇠부터 확인한다.
6. 트레이를 원래 위치에 넣고 케이블을 연결한 뒤 전원을 켠다.

접점과 다른 내부 부품은 만지지 않는다. 모듈을 뺄 때는 양쪽 걸쇠를 벌려 풀고 가장자리를 잡는다. 위 위치·고정 방식은 공식 가이드를 참고한 설명이며, 16GB 구성은 제조사 권장 범위를 벗어난다.

## DSM에서 16GB로 인식되는지 확인

전원을 켠 뒤 DSM에 접속해 **제어판 → 정보 센터**에서 총 물리적 메모리를 확인한다. 내 리소스 모니터 화면에서도 합계가 **16GB**로 표시됐다.

![합계 16GB와 사용량 16%가 표시된 실제 DSM 리소스 모니터 화면](/images/server/blog-nas/ds918-memory-upgrade/memory-status-alpha-v3.webp)

이 화면에는 사용된 공간, 캐시된 영역, 남은 영역이 따로 표시되어 있다. 합계 16GB로 인식됐다는 것은 확인할 수 있지만, 사용량 16%라는 숫자는 캡처한 순간의 상태다. 이것을 4GB와 16GB의 성능 비교나 장시간 안정성 검사 결과로 볼 수는 없다. 화면에 나오지 않는 DSM 세부 빌드나 모듈 리비전까지 확인되는 것도 아니다.

## 메모리 검사와 문제가 생겼을 때

용량이 제대로 잡히는 것과 메모리에 오류가 없는지는 별도로 확인할 부분이다. Synology Assistant에는 메모리 검사 기능이 있다. [Assistant 도움말](https://kb.synology.com/en-id/DSM/help/Assistant/assistant?version=6)과 [Synology의 메모리 검사 안내](https://kb.synology.com/en-sg/DSM/tutorial/How_can_I_run_a_memory_test_on_my_Synology_NAS)를 참고할 수 있다.

1. PC나 Mac에서 Synology Assistant를 열고 설정에서 메모리 검사 기능을 활성화한다.
2. 사용할 NAS를 선택하고 메모리 검사를 실행한다.
3. 검사 중에는 NAS가 재시작되고 서비스를 사용할 수 없으므로 진행 중인 작업을 먼저 정리한다. Assistant도 종료하지 않는다.
4. 끝난 뒤 상태 표시와 오류 메시지를 확인한다. 검사 뒤 NAS가 검색된다는 이유만으로 오류가 없었다고 판단하지 않는다.

내 사용 소감은 인식 용량과 사용하는 동안의 체감에 관한 것이다. 이 글에 별도의 검사 통과 화면이나 반복 검사 결과를 남긴 것은 아니므로, 검사 기능을 소개하는 내용과 내 검증 결과를 혼동하지 않았으면 한다.

부팅되지 않거나 사용 중 재시작 같은 문제가 생긴다면 새 메모리를 계속 쓰기보다 기존 구성으로 되돌려 원인을 나누어 보는 편이 좋다.

1. 정상 종료할 수 있으면 종료하고, 전원과 케이블을 분리한 상태에서 장착 상태를 확인한다.
2. 새 모듈을 빼고 기존 Synology 4GB 메모리를 원래 슬롯에 되돌린다.
3. 트레이를 같은 순서로 넣고 연결한 뒤, 부팅과 DSM 접속이 정상인지 확인한다.
4. 기존 구성에서도 문제가 이어지면 다른 원인도 확인하고 제조사 지원을 받는다.

메모리 교체를 위해 볼륨을 새로 만들거나 디스크를 초기화할 이유는 없다. 부팅 중 설치·초기화 안내가 나온다면 그대로 진행하지 말고 드라이브와 연결 상태부터 확인해야 한다. 문제를 확인하는 동안에도 기존 메모리는 버리지 않고 보관해 두는 편이 좋겠다.

## 써 보니 어떤가

메모리가 넉넉해지니 이것저것 올리는 데 부담이 줄었다. 돈을 너무 쓴 건 아닌가 싶기도 했지만, 쓰는 입장에서는 빠릿해진 느낌이 있어 만족스럽다. 다만 별도로 처리 시간이나 전송 속도를 재 본 것은 아니라 ‘얼마나 빨라졌다’고 숫자로 말할 수는 없다. 메모리를 늘렸다고 디스크나 네트워크 속도까지 함께 올라가는 것도 아니다.

공식 최대 용량은 8GB이고, 내가 사용한 16GB는 그 범위를 벗어난 개인 사례라는 점은 다시 구분해 두고 싶다. 기존 Synology 4GB 메모리는 어떻게 처분할까 싶었는데, 원래 구성으로 돌아갈 때를 생각하면 당분간 가지고 있어야겠다.
