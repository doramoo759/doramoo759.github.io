# 시놀로지 DS918+ USB 2.5G 랜카드 설치 후기와 인식 불안정으로 원복한 이유

date: 2022-11-16

> ipTIME U2500과 r8152 드라이버로 구성한 DS918+ 2.5G 연결. 설치 과정과 전송 속도, 철거한 이유.


![DS918+ 2.5G 네트워크 구성 이미지](/images/server/ds918-25g/cover.png)

PC에서 2.5G LAN을 쓸 수 있으니 DS918+도 같은 속도로 연결해 보고 싶었다. NAS를 바꾸는 대신 USB LAN 어댑터와 2.5G 스위칭 허브를 붙였다.

속도는 잘 나왔다. PC에서 NAS로 복사할 때 약 290MB/s, 반대 방향은 약 220MB/s였다. 다만 쓰다 보니 간헐적으로 네트워크가 먹통이 됐고, 결국 어댑터를 빼고 원래 구성으로 돌아갔다.

## 사용한 장비

- 2.5G LAN을 지원하는 PC
- ipTIME USB 3.0 U2500 (`RTL8156` 칩셋)
- 2.5G 스위칭 허브
- Synology DS918+

DSM에서 USB LAN을 쓰려면 별도 드라이버가 필요하다. 어댑터를 고를 때는 [r8152 호환 목록](https://github.com/bb-qq/r8152/wiki/Compatibility)을 확인했다.

내 DS918+에서는 후면 USB 포트의 인식이 불안정했고, 전면 포트에서는 비교적 잘 잡혔다. 그래서 전면 포트에 연결해서 사용했다.

## r8152 드라이버 설치

[bb-qq/r8152 릴리스](https://github.com/bb-qq/r8152/releases)에서 NAS 모델과 DSM 버전에 맞는 `spk` 파일을 받는다. DSM 패키지 센터의 **수동 설치**로 진행하면 된다.

![DSM 패키지 수동 설치 화면](/images/server/ds918-25g/manual-install.webp)

설치 중 오류가 나서 SSH로 접속해 아래 명령을 실행한 뒤 다시 설치했다. 당시 사용한 패키지에서 필요한 조치였다.

```bash
sudo install -m 4755 -o root -D /var/packages/r8152/target/r8152/spk_su /opt/sbin/spk_su
```

설치가 끝나면 패키지 센터에서 드라이버 상태를 확인한다.

![DSM r8152 드라이버 설치 확인](/images/server/ds918-25g/driver-installed.webp)

## 인터페이스 설정과 연결

제어판의 **네트워크 인터페이스**에 USB LAN이 추가된 것을 확인하고, 편집 화면에서 `Jumbo Frame`을 `9K`로 설정했다. 아래는 당시 사용한 설정이다.

![점보 프레임 9K 설정 화면](/images/server/ds918-25g/jumbo-frame.webp)

PC와 NAS를 직접 연결해 수동 IP를 잡는 방법도 있지만, 나는 2.5G 스위칭 허브에 연결했다.

![2.5G 스위칭 허브 구성 예시 1](/images/server/ds918-25g/switch-01.webp)

![2.5G 스위칭 허브 구성 예시 2](/images/server/ds918-25g/switch-02.webp)

이 구성에서 측정한 전송 속도는 다음과 같다. 내 환경에서 파일을 복사하며 확인한 수치이다.

| 방향 | 전송 속도 |
| --- | --- |
| PC → NAS | 약 290MB/s |
| NAS → PC | 약 220MB/s |

1GbE로 쓰던 때보다 파일 복사는 확실히 빨라졌다.

## 결국 철거했다

처음에는 잘 썼지만, 사용을 이어 가면서 간헐적으로 네트워크가 멈추는 문제가 생겼다. 드라이버를 중지했다가 다시 로드하면 복구됐다. 계속 켜 두는 NAS에서 그 작업을 반복해야 한다는 게 불편했다.

전면 포트를 써야 하는 것도 마음에 걸렸다. 어댑터와 랜선이 앞에 계속 꽂혀 있으니 케이블 정리가 깔끔하지 않았다.

속도만 보면 아쉬운 업그레이드는 아니었다. 그래도 내 NAS에서는 안정성과 케이블 정리 문제 때문에 오래 유지하지 못했다.
