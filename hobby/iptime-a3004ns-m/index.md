# ipTIME A3004NS-M 가성비 기가 와이파이 공유기 실사용기: 간이 NAS 끄고 공유기로만 쓴 이유

date: 2020-07-26

> VPN과 USB 간이 NAS에서는 문제가 있었지만, 공유기 기능만 쓰니 안정적이었다. 2020년 사용 기록.


사용하던 공유기가 오래돼서 ipTIME A3004NS-M을 골랐다. 가격과 기능을 보고 적당하겠다 싶어 산 5만 원대 가정용 공유기다.

![ipTIME A3004NS-M, 공유기로만 쓰니 괜찮았다 — 화면 1](/images/server/blog-nas/iptime-a3004ns-m/photo-01.png)

우연히 같은 제품을 두 개 샀다. 거실에 놓고 쓴 지 1년쯤 됐을 때의 기록이다.

## VPN과 간이 NAS는 포기

처음 한두 달은 회사에서 VPN이 필요해서 써 봤다. 연결이 하루를 못 가고 자주 끊겨서 포기했다.

USB 3.0에 저장 장치를 붙여 간이 NAS로도 써 봤지만, 3개월을 못 가고 제품이 먹통이 됐다.

고장 난 제품은 A/S를 보내고, 다른 한 대를 거실에 두었다. 이번에는 공유기 기능 외에는 쓰지 않았다.

![ipTIME A3004NS-M, 공유기로만 쓰니 괜찮았다 — 화면 2](/images/server/blog-nas/iptime-a3004ns-m/photo-02.png)

## 공유기로만 쓰니 안정적이었다

그렇게 8개월 동안 한 번도 끊기지 않고 돌아갔다. 당연한 일이라고 할 수도 있지만 기대가 크지 않았던 만큼 의외로 만족했다.

고장 났던 제품은 일반 인터넷 연결도 자주 끊겨 새벽에 재부팅하도록 설정해 쓰고 있었다.

사용량이 많지는 않았다. BTV, 인터넷, 휴대폰 3~4대, NAS 연결, 가끔 토렌트 정도다. 내 환경에서는 공유기 본래 기능만 쓸 때 꽤 잘 버텼다.
