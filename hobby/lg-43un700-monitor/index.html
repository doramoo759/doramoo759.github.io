LG 43UN700 43인치 4K 모니터 실사용기 — 맥북 연결 및 CalDigit DP 색상 왜곡 해결법

Created Date: 2021.01.01 Last Updated: 2026.10.09

  1. Home
  2. / Hobby
  3. / LG 43UN700 43인치 4K 모니터 실사용기 — 맥북 연결 및 CalDigit DP 색상 왜곡 해결법

LG 43UN700을 약 2주 사용하고 적은 후기다. 설치 기사가 빠르게 설치해 주고 가서 언박싱 사진은 없다.

크기

회사에서 40인치 커브드 모니터를 쓰고 있어 큰 화면 자체는 익숙했다. 42.5인치라 조금 더 큰 느낌이지만 적당해 보였다.

모니터 아래에 놓인 CalDigit TS3 Plus와 비교하면 크기가 짐작된다.

색상 때문에 한참 헤맸다

기존 모니터의 색감이 좋지 않아 MacBook 화면과 맞추는 데 시간을 쓰곤 했다. 그래서 이번에는 색상을 중요하게 봤다.

그런데 연결하니 화면이 붉게 보였다. 방법을 찾아보고 서비스센터에도 문의했지만 제품에는 이상이 없다는 답변이었다. 아마존 후기에서도 비슷한 이야기를 보고 며칠은 그냥 쓰다가 원인을 찾았다.

내 구성에서는 모니터의 DP 버전과 CalDigit TS3 Plus 연결이 관련 있었다. 모니터의 DP 설정을 1.2로 낮춘 뒤 원하는 색상을 볼 수 있었다. USB-C로 연결했는데 왜 DP 단자 설정의 영향을 받는지는 당시에도 잘 모르겠었다.

DP 1.4에서 HDR이 자동으로 켜지면 색상 조정 메뉴를 쓸 수 없어 더 답답했다.

연결과 편의 기능

USB 허브 기능이 의외로 마음에 들었다. USB-C 하나로 화면과 USB 기기를 연결해서 별도 허브를 치웠다.

앱으로 모니터를 제어하는 기능도 있었다. 여러 입력을 쓰면 편하겠지만 MacBook 하나만 연결해서 실제로 써 보지는 않았다.

높이 조절이 없는 것은 아쉽다. 큰 모니터를 책상에 올려 놓으면 높이를 낮춰야 편한데, 위를 올려다보게 되면 불편하다.

큰 화면과 USB-C 연결, 별도 스피커가 필요 없을 정도의 소리는 괜찮았다. 다만 모니터가 두꺼워 TV 프레임을 그대로 쓴 것 같은 느낌이었다.
