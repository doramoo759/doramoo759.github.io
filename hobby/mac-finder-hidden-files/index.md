# Mac Finder 숨김 파일 보기: 단축키·터미널 명령과 Linux·Windows 비교

date: 2019-10-29

> Mac Finder에서 Cmd+Shift+.로 숨김 파일을 표시하고 다시 숨기는 방법. 터미널 설정과 원복 명령, Linux GNOME·Windows 11의 표시 방법도 비교합니다.


Mac Finder에서 숨김 파일을 보려면 **`Command(⌘) + Shift(⇧) + .`**을 누른다. 마지막 키는 마침표다. 같은 단축키를 다시 누르면 숨김 파일이 보이지 않는 상태로 돌아간다.

원래는 한 번 설정하고 잊기 쉬운 Finder 터미널 명령을 적어 둔 글이었다. 단축키로 처리하는 방법과 원복 방법을 보완하고, Linux와 Windows에서는 같은 작업을 어떻게 하는지 함께 정리했다.

## 운영체제별 숨김 파일 표시 방법

| 환경 | 표시 방법 | 다시 숨기는 방법 |
| --- | --- | --- |
| Mac Finder | `Command + Shift + .` | 같은 단축키를 다시 누른다 |
| Linux의 GNOME 파일 관리자 | `Ctrl + H` 또는 메뉴의 숨김 파일 표시 | 같은 단축키를 다시 누르거나 메뉴 선택을 해제한다 |
| Windows 11 파일 탐색기 | 보기 → 표시 → 숨긴 항목 | 숨긴 항목의 선택을 해제한다 |

Linux는 배포판 이름보다 **어떤 파일 관리자를 사용하는지**가 중요하다. 위의 `Ctrl + H`는 GNOME의 파일 관리자 기준이며, 다른 파일 관리자에서는 단축키나 메뉴 위치가 다를 수 있다.

이 글의 Mac 명령은 2019년 메모를 바탕으로 보완했다. Linux·Windows 설명은 문서 기반이며, 이번 수정에서 각 운영체제의 화면을 직접 실행해 검증한 것은 아니다. Windows 메뉴는 Windows 11 기준이다.

## Mac: Finder에서 단축키로 보기

1. Finder를 열고 확인할 폴더로 이동한다.
2. Finder 창을 선택한 상태에서 `Command + Shift + .`을 누른다.
3. 해당 폴더에 숨김 항목이 있다면 표시되는지 확인한다.
4. 확인이 끝나면 같은 단축키를 다시 눌러 숨긴다.

예를 들어 개발 프로젝트의 `.git` 폴더나 `.gitignore` 파일처럼 이름 앞에 점이 붙은 항목을 확인할 때 쓸 수 있다. 해당 폴더에 숨김 항목이 없다면 단축키를 눌러도 눈에 띄는 변화가 없을 수 있다.

반응이 없다면 먼저 Finder 창에 입력 초점이 있는지 확인한다. 이어서 영문 입력 상태와 키보드의 마침표 키를 확인한다. 키보드 배열이나 단축키 충돌에 따른 차이는 [Apple 지원 커뮤니티의 Catalina 사용자 사례](https://discussions.apple.com/thread/250756110)에도 기록돼 있다. 이 링크는 Apple의 공식 지원 사양이 아닌 사용자 경험 공유다.

## Mac: 터미널에서 표시 설정하기

터미널 앱을 열고 다음 명령을 한 줄씩 실행한다. 현재 사용자 Finder 설정을 바꾸는 작업이므로 `sudo`는 필요하지 않으며, 특정 폴더로 이동할 필요도 없다.

```bash
defaults write com.apple.finder AppleShowAllFiles -bool true
killall Finder
```

첫 줄은 숨김 파일 표시 설정을 켜고, 두 번째 줄은 Finder를 종료해 다시 시작하도록 한다. Finder 창이 잠시 사라질 수 있으므로 파일 복사나 이동이 끝난 뒤 실행한다. 다시 열린 Finder에서 숨김 항목이 있는 폴더를 확인하면 된다.

원래 메모에서는 `com.apple.Finder`와 `TRUE` 표기를 사용했다. 위 예제는 설정 도메인을 `com.apple.finder`로 쓰고, `-bool true`로 참·거짓 값임을 명시했다.

### 다시 숨기기

숨김 파일 표시를 끄려면 다음과 같이 실행한다.

```bash
defaults write com.apple.finder AppleShowAllFiles -bool false
killall Finder
```

이 명령은 숨김 파일 표시를 끄는 방법이다. 수정 전에 표시를 켜 둔 상태였다면 기존 설정과 달라지므로, 작업 전에 어떤 상태였는지 확인해 두는 편이 좋다. 단축키로 해결된다면 터미널 설정을 추가로 바꿀 필요는 없다.

## Linux: 점으로 시작하는 파일과 GNOME의 Ctrl+H

Linux에서는 `.bashrc`, `.config`처럼 **이름이 점(`.`)으로 시작하는 파일·디렉터리**를 기본 목록에서 숨기는 관례가 있다. Ubuntu 등에서 GNOME의 파일 관리자를 사용한다면 폴더를 연 뒤 `Ctrl + H`를 눌러 표시를 전환할 수 있다. 메뉴의 **숨김 파일 표시(Show Hidden Files)**를 선택해도 된다. [GNOME 공식 도움말](https://help.gnome.org/gnome-help/files-hidden.html)

터미널에서는 확인할 디렉터리로 이동한 뒤 다음 명령을 사용한다.

```bash
ls -la
```

`-l`은 자세한 목록, `-a`는 점으로 시작하는 항목을 포함해 표시하는 옵션이다. `.`은 현재 디렉터리, `..`는 상위 디렉터리를 뜻하므로 목록에서 함께 보일 수 있다. 이 둘을 제외하면서 숨김 항목을 보려면 `ls -lA`를 사용한다. [GNU ls 옵션 설명](https://www.gnu.org/software/coreutils/manual/html_node/Which-files-are-listed.html)

`ls`는 목록을 조회하는 명령이라 파일 관리자의 표시 설정을 바꾸지 않는다. 이후 `ls`만 실행하면 기본 목록으로 확인할 수 있다.

## Windows 11: 파일 탐색기의 숨긴 항목

Windows 11에서는 다음 순서로 설정한다.

1. `Windows 키 + E`로 파일 탐색기를 연다.
2. 상단의 **보기 → 표시 → 숨긴 항목**을 선택한다.
3. 확인할 폴더에서 숨김 항목이 표시되는지 확인한다.
4. 다시 숨기려면 같은 메뉴의 선택을 해제한다.

Microsoft의 [파일 탐색기 공식 안내](https://support.microsoft.com/en-gb/windows/experience/fileexplorer/file-explorer-in-windows?nochrome=true)에 나온 경로다. Windows 10은 **보기 → 옵션 → 폴더 및 검색 옵션 변경 → 보기**에서 **숨김 파일, 폴더 및 드라이브 표시**를 선택하는 경로로 안내돼 있다.

Windows는 파일의 **숨김 속성**을 사용하므로, Linux처럼 파일명 앞에 점을 붙이는 것만으로 같은 의미의 숨김 설정이 되지는 않는다. 또한 숨긴 항목 표시와 보호된 운영체제 파일 표시는 별도 설정이다. 일반적인 숨김 파일 확인을 위해 보호된 운영체제 파일까지 표시할 필요는 없다.

## 표시 설정과 파일 접근 권한은 다르다

숨김 파일을 표시하는 작업은 파일을 삭제하거나 이름을 바꾸는 작업이 아니다. 반대로 파일을 숨겨 둔다고 다른 사용자의 접근이 차단되는 것도 아니다. 접근을 제한하려면 파일 권한이나 암호화처럼 별도의 보호 방법이 필요하다.

설정 파일을 수정하려는 경우에는 먼저 복사본을 보관한다. 특히 `.git`이나 시스템 설정 폴더는 숨김 항목이라는 이유만으로 정리하거나 삭제하지 않는다. 필요한 항목만 확인한 뒤 표시 설정을 되돌리면 된다.
