## 나의 의견

감성주택은 나중에 상담을 한번 받아 보고 싶은 업체다. 집을 짓는 것도 중요하지만, 영상을 보면 하자 관리에도 중점을 두는 듯하다.

이중 배관은 이 영상을 보면서 처음 알았다. 유용한 정보라 나중에 다시 보려고 기록해 둔다.

실제 현장에서도 어떻게 적용하고 관리하는지는 상담할 때 물어보고 싶다. 대표가 모든 공사를 쫓아다닐 수는 없으니, 현장마다 시공 상태를 확인하고 하자를 관리하는 과정도 궁금하다.

## 나중에 시공사에 물어볼 것

공법 이름을 기억하는 데서 끝나면 별 도움이 안 될 것 같다. 내 집에 적용한다면 배관이 어디로 지나가는지, 연결 부위는 어디에 있는지, 문제가 생겼을 때 어느 부분을 열어야 하는지부터 설명을 듣고 싶다. 영상만으로는 이 공법의 적용 범위나 수리 과정을 알 수 없다.

벽과 바닥을 덮기 전에 배관 위치를 사진과 도면으로 남겨 주는지도 물어볼 것. 시공한 사람과 확인하는 사람이 누구인지, 확인 결과를 건축주도 볼 수 있는지가 궁금하다. 대표가 현장에 오는 날뿐 아니라 평소에도 같은 방식으로 점검하는지가 더 중요한 비교 항목이다.

견적을 비교할 때도 ‘이 공법을 쓴다’는 설명 옆에 점검 기록과 인수인계 자료가 포함되는지 적어 두려고 한다. 하자가 생기면 어디로 연락하고 어떤 순서로 확인하는지도 미리 물어봐야겠다. 아직 업체를 비교하거나 직접 시공을 확인한 기록은 아니고, 상담할 때 놓치지 않으려는 메모다.
