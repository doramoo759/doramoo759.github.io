# 오픈소스

date: 2026-10-16

> ramoo.net의 구축·유지에 사용하는 오픈소스와 콘텐츠 라이선스를 안내합니다.


ramoo.net은 오픈소스 소프트웨어로 만들었습니다. 주요 도구로 정적 사이트 생성기 Hugo, Hugoplate 테마, Tailwind CSS, Prettier와 Hugo 모듈·npm 패키지를 사용합니다.

## 소프트웨어와 콘텐츠 라이선스

각 소프트웨어 구성요소에는 원 프로젝트의 라이선스가 적용됩니다. 주요 구성요소, 라이선스 링크와 외부 자료는 [제3자 권리 고지](/ko/third-party-notices/)에서 확인할 수 있습니다.

이러한 소프트웨어 라이선스가 블로그 글, 원본 예제와 원본 이미지에 자동으로 적용되지는 않습니다. 해당 자료의 재사용에는 [콘텐츠 이용허락](/ko/license/)이 적용됩니다. 별도 라이선스를 명시한 예제는 해당 라이선스를 따릅니다.

## 라이선스 기록

소프트웨어에 포함된 저작권 고지, 라이선스 전문과 재배포 조건은 필요한 경우 보존해야 합니다. 이 소개는 각 구성요소와 함께 배포되는 라이선스를 대체하지 않습니다.

소프트웨어의 출처 표시와 라이선스 고지는 [문의 페이지](/ko/contact/)로 문의하세요.
