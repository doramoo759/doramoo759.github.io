ramoo.net은 ramoo가 운영하는 개인 블로그입니다. 회원가입 기능은 제공하지 않습니다. 이 방침은 사이트 방문, 문의, 댓글 및 외부 기능 이용 시 처리되는 정보를 설명합니다.

처리하는 정보와 목적

구분처리되는 정보목적
페이지 제공·보안IP 주소, 요청 URL·시각, 브라우저·기기 및 연결 정보페이지와 이미지 제공, 오류 확인, 부정 접속 방지
문의이름, 이메일 주소, 문의 내용과 답변 기록문의 확인, 답변 및 후속 문의 처리
방문 통계방문 페이지, 방문·이벤트 시각, 브라우저·기기 및 통계용 식별 정보사이트 이용 현황 파악과 개선
댓글공개 GitHub 프로필, 댓글·반응GitHub Discussions 기반 댓글 제공
IP 확인 도구공인 IP, IP 기반 추정 위치·네트워크, 요청 헤더·연결 정보현재 접속의 IP·네트워크 정보 표시

사이트 운영에 필요하지 않은 민감정보, 비밀번호, 주민등록번호 등은 문의나 댓글에 입력하지 마세요.

Google Analytics 방문 통계

현재 사이트에는 Google Analytics 4가 설정되어 있습니다. 방문자가 방문 통계를 허용한 뒤에만 Google 분석 태그를 불러옵니다. 선택 전이나 거부 상태에서는 이 사이트의 분석 태그를 불러오지 않습니다. 광고용 Google Signals와 광고 개인화 신호는 코드에서 비활성화합니다.

허용·거부는 쿠키 정책의 방문 통계 설정에서 변경할 수 있습니다. 거부하면 이후 이 사이트의 분석 전송을 중단하고 접근 가능한 Analytics 쿠키를 삭제합니다. 이미 전송된 정보가 자동 삭제되는 것은 아닙니다. 브라우저의 Do Not Track 신호는 저장된 명시적 선택이 없는 경우 거부로 처리합니다.

Google AdSense와 별도의 Google Tag Manager 컨테이너는 현재 활성화되어 있지 않습니다. 분석 태그의 파일 주소에 googletagmanager.com이 포함되더라도 Tag Manager 컨테이너 사용을 뜻하지는 않습니다. Google의 정보 처리에 관해서는 Google 개인정보처리방침과 Analytics 데이터 보호 안내를 참고하세요.

문의와 Formspree

문의 폼의 이름·이메일 주소·문의 내용은 전송 버튼을 누를 때 HTTPS 요청으로 Formspree, Inc.에 전달되고 운영자가 문의에 답변하는 데 사용합니다. 문의는 선택 사항이며 동의하지 않으면 폼을 통한 문의를 전송할 수 없습니다.

Formspree는 미국 및 서비스를 운영하는 다른 국가에서 정보를 처리한다고 안내합니다. 서비스는 스팸·부정 이용 방지 등을 위해 IP, 브라우저, 접속 시각 같은 요청 정보를 추가 처리할 수 있습니다. 제공자의 처리와 해외 처리에 관한 설명은 Formspree 개인정보처리방침에서 확인할 수 있습니다.

운영자가 관리하는 문의 내용과 답변 이메일은 답변 완료 후 90일 이내에 삭제합니다. 삭제 요청이 먼저 접수되면 본인 확인에 필요한 최소한의 확인 후 처리합니다. Formspree 수신함과 운영자의 이메일에 남은 사본도 삭제 대상에 포함합니다. 제공자가 보안·법적 의무에 따라 별도로 관리하는 로그와 백업에는 해당 제공자의 보관 정책이 적용되므로 모두 같은 시점에 삭제된다고 보장하지 않습니다.

사이트 제공과 외부 기능

  • GitHub·Cloudflare: 사이트 배포, 이미지 전달, API 연결 및 보안 처리 과정에서 접속 정보가 처리될 수 있습니다. GitHub 개인정보처리방침, Cloudflare 개인정보처리방침을 참고하세요. 제공자가 관리하는 로그의 보관 기간은 해당 서비스와 실제 설정에 따릅니다.
  • TradingView: 홈의 시세 위젯은 페이지를 열면 TradingView에 연결됩니다. 공식 FAQ는 위젯이 쿠키를 설정하지 않으며, 위젯 제공을 위해 삽입된 페이지 URL, 위젯 종류, 표시 종목과 IP 주소를 처리한다고 설명합니다. 공식 위젯 FAQ, 개인정보처리방침을 참고하세요. 방문 통계 거부는 이 시세 연결을 차단하는 설정이 아닙니다.
  • IP 확인 API: IP 확인 페이지를 열거나 다시 조회하면 브라우저가 https://api.ramoo.net/ip에 요청하여 공인 IP, 대략적인 위치·네트워크·연결 정보를 표시합니다. 조회 결과를 브라우저의 쿠키나 로컬 저장소에 보관하지 않으며, 조회 요청에는 브라우저 인증정보를 포함하지 않습니다. API·호스팅 계층의 접속 로그까지 저장되지 않는다는 뜻은 아닙니다. API·호스팅 제공자의 접속 로그에는 해당 제공자의 운영·보관 정책이 적용됩니다.
  • OpenStreetMap: IP 기반 추정 위치가 있을 때 지도 타일을 tile.openstreetmap.org에서 가져옵니다. 이 요청으로 IP 주소와 요청 헤더, 타일 좌표로 알 수 있는 표시 지역이 지도 제공자에게 전달될 수 있습니다. 브라우저 GPS 위치 권한을 요청하는 기능은 아닙니다. OSMF 개인정보처리방침을 참고하세요.
  • Giscus·GitHub 댓글: 댓글 위젯 로딩 시 Giscus에 연결됩니다. 댓글 작성에는 GitHub 로그인과 승인이 필요하며 댓글·반응은 공개 GitHub Discussions에 저장됩니다. 공개 프로필과 작성 내용은 다른 방문자도 볼 수 있습니다. Giscus 설명과 GitHub 개인정보처리방침을 참고하세요.
  • 기타 외부 콘텐츠: 게시글의 외부 영상·리소스를 불러오거나 링크를 방문하면 해당 제공자에게 접속 정보가 전달될 수 있습니다. 해당 서비스의 자체 정책이 적용됩니다.

보관과 삭제, 권리 행사

문의 정보는 위의 90일 기준에 따라 운영자가 Formspree 수신함과 이메일에서 삭제합니다. 방문 통계 선택은 브라우저에 180일간 유효한 설정으로 보관하며, 테마 설정과 쿠키는 쿠키 정책에서 설명합니다. Google Analytics 서버에 저장된 통계와 외부 제공자의 로그 보관은 각 계정 설정과 제공자 정책에 따릅니다.

자신의 개인정보에 대한 열람·정정·삭제, 처리 정지, 동의 철회 또는 문의를 원하면 Contact에서 문의 종류와 요청 내용을 보내 주세요. 운영자는 요청자 확인에 필요한 최소 정보만 확인하고 요청을 처리하여 답변합니다. 방문 통계 동의는 쿠키 정책 페이지에서 직접 철회할 수 있습니다. GitHub 공개 댓글은 해당 계정의 댓글 관리 기능으로 수정·삭제할 수 있으며 운영자에게도 문의할 수 있습니다.
