# 제3자 권리 고지

date: 2026-10-16

> ramoo.net에서 사용하는 소프트웨어와 외부 자료의 출처·라이선스를 안내합니다.


ramoo.net에서 사용하는 소프트웨어와 제3자 자료에는 해당 권리자의 권리와 원 프로젝트의 라이선스가 적용됩니다.

## 주요 소프트웨어

| 구성요소 | 용도 | 라이선스 |
| --- | --- | --- |
| [Hugo](https://gohugo.io/) | 정적 사이트 생성기 | [Apache License 2.0](https://github.com/gohugoio/hugo/blob/master/LICENSE) |
| [Zeon Studio의 Hugoplate](https://github.com/zeon-studio/hugoplate) | 테마와 프로젝트 기본 구조 | [MIT](https://github.com/zeon-studio/hugoplate/blob/main/LICENSE) |
| [Tailwind CSS](https://tailwindcss.com/) | CSS 도구 | [MIT](https://github.com/tailwindlabs/tailwindcss/blob/main/LICENSE) |
| [Prettier](https://prettier.io/) | 소스 포맷팅 | [MIT](https://github.com/prettier/prettier/blob/main/LICENSE) |

추가 Hugo 모듈, 프런트엔드 라이브러리와 간접 의존성에는 각각의 라이선스가 적용됩니다. 이 표는 주요 구성요소만 소개하며 전체 의존성 목록이나 소프트웨어에 포함된 저작권 고지·라이선스 전문을 대체하지 않습니다.

## 외부 자료와 출처 표시

제품명, 로고, 상표, 제품 디자인, 스크린샷과 서비스 화면에는 제3자 소유 자료가 포함될 수 있습니다. 사이트는 해당 요소의 소유권을 주장하지 않습니다.

외부 이미지나 자료의 출처와 권리 표시는 관련 글 또는 자료 고지에 기록해야 합니다. 원본 라이선스에서 요구하는 경우 원문 URL, 제작자·배포자, 라이선스 링크와 변경 내용을 포함합니다.

## 사이트 원본 콘텐츠

작성자의 원본 자료에 대한 이용허락은 [콘텐츠 이용허락](/ko/license/)에서 설명합니다. 소프트웨어와 콘텐츠 라이선스의 구분은 [오픈소스](/ko/open-source/)에서 확인할 수 있습니다.
