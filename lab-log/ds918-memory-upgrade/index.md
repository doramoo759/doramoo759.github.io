# 시놀로지 DS918+ RAM 메모리 16GB 업그레이드 방법 및 호환 메모리 확인기

date: 2019-11-02

> DS918+에 CT2K102464BF186D 메모리를 장착한 기록. 사용 중 느낀 변화와 남은 기존 메모리 이야기.


DS918+를 사고 메모리를 늘리려고 알아봤다. 아무 메모리나 사서 꽂으면 되는 것은 아니어서 아래 모델을 골랐다.

```text
DDR3L 1866 MT/s (PC3-14900)
Unbuffered SODIMM 204-Pin
CT2K102464BF186D
```

![DS918+ 메모리 업그레이드 — 화면 1](/images/server/blog-nas/ds918-memory-upgrade/photo-01.jpeg)

아마존에서 샀다. 처음에는 8GB 하나만 사려고 했는데, 해외에서 오는 김에 세트로 주문했다.

## 장착 후

메모리 용량이 많이 남았다. 돈을 너무 쓴 건 아닌가 싶었지만 체감상 확실히 빠릿해진 느낌이었다.

![DS918+ 메모리 업그레이드 — 화면 2](/images/server/blog-nas/ds918-memory-upgrade/photo-02.png)

당시 사용 중에는 안정적으로 동작했다. 메모리가 넉넉하니 이것저것 올리는 데 부담이 줄어 만족했다.

기존 Synology 4GB 메모리는 어떻게 처분할지 고민이었다.
