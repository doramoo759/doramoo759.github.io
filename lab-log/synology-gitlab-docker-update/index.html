Synology GitLab CE 컨테이너 업데이트 메모

Created Date: 2022.03.22 Last Updated: 2026.10.09

  1. Home
  2. / Dev Log
  3. / Synology GitLab CE 컨테이너 업데이트 메모

GitLab CE를 Docker Registry에서 받아 설치해 두었다. 설치한 이미지를 업데이트하는 방법을 찾아보다가 기록으로 남긴다.

2022년에 14.8.3-ce.0에서 14.8.4-ce.0으로 바꿀 때 사용한 DSM Docker 화면 기준이다.

새 이미지 받기

DSM > Docker > Registry에서 gitlab을 검색해 필요한 버전을 다운로드한다.

latest보다 버전을 지정해 두는 편이 다음 업데이트 때 관리하기 편하다. 당시에는 14.8.4-ce.0을 받았다.

설정 내보내기

DSM > Docker > Container에서 기존 GitLab CE 컨테이너를 선택하고, 우클릭 메뉴의 설정 > 내보내기를 선택한다.

적당한 폴더를 골라 내보낸다.

선택한 폴더에 JSON 파일이 생긴다.

텍스트 편집기로 연다.

이미지 이름의 버전을 새로 받은 버전으로 바꾸고 저장한다.

"image": "gitlab/gitlab-ce:14.8.3-ce.0"

위 값을 다음과 같이 바꿨다.

"image": "gitlab/gitlab-ce:14.8.4-ce.0"

컨테이너 교체

기존 컨테이너를 중지한다.

중지한 컨테이너를 삭제한다. 삭제하기 전에는 데이터를 백업하고, 버전 사이에 필요한 마이그레이션 경로도 확인해야 한다. 내보낸 설정 파일만으로 데이터 백업을 대신할 수는 없다.

DSM > Docker > Container > 설정 > 가져오기에서 수정한 파일을 선택한다.

새 버전으로 GitLab CE를 실행한다.

다른 Docker 이미지도 설정을 내보내고 이미지 버전을 바꾸는 방식으로 교체할 수 있다. 다만 애플리케이션마다 데이터와 버전 호환 조건은 따로 확인할 것.
