# Catalina에서 사라진 iTunes를 찾다가

date: 2019-11-01

> iTunes를 찾다가 Catalina에서는 Finder로 기기를 동기화한다는 것을 알게 됐다.


개발하다 앱에 파일을 올릴 일이 있어 iTunes를 찾았는데 아무리 봐도 없었다.

![Catalina에서 사라진 iTunes를 찾다가 — 화면 1](/images/off-duty/macos-catalina-itunes/photo-01.png)

macOS Catalina에서는 iTunes의 기능이 나뉘고, 기기 동기화는 Finder에서 할 수 있었다.

Finder를 열면 왼쪽에 연결한 기기가 나타난다. 선택하면 예전에 iTunes에서 보던 동기화 화면이 나온다.

![Catalina에서 사라진 iTunes를 찾다가 — 화면 2](/images/off-duty/macos-catalina-itunes/photo-02.png)

찾았으니 이제 하던 일을 계속한다.
