# 웹 브라우저 기반 원격 접속 Apache Guacamole 사내망 구축 및 RDP/SSH 테스트

date: 2026-04-24

> 브라우저 SSH 접속은 편했지만 LDAP 연동과 계정·세션 관리가 걸렸다. 사내망 테스트에서 멈춘 기록.


![Apache Guacamole 소개 이미지](/images/server/apache-guacamole-cover.webp)

사내 서버에 Apache Guacamole를 설치해서 원격접속을 테스트했다. 사내망에서만 접근할 수 있게 열어 두었고, 기본 기능을 확인한 뒤 정식 운영으로 이어가지는 않았다.

브라우저에서 SSH에 접속할 수 있는 건 편했다. 다만 LDAP 연동이 기대만큼 안정적이지 않았고, 계정과 세션을 관리할 부담도 있었다.

## 브라우저로 원격접속하기

Guacamole는 웹에서 RDP, VNC, SSH 연결을 사용할 수 있게 해 주는 도구다. 접속하는 PC에 별도 클라이언트를 설치하지 않아도 된다. 관리자가 계정별로 연결 대상을 등록하면 사용자는 로그인해서 자신에게 허용된 장비를 선택한다.

[공식 사이트](https://guacamole.apache.org/)와 [설치·운영 매뉴얼](https://guacamole.apache.org/doc/gug/)을 참고했다. 아래는 공식 사이트의 데모 영상이다.

## 테스트에서 확인한 기능

관리자 로그인, 계정별 연결 목록, SSH 접속, 연결 로그, 세션 재생, 사용자 설정을 확인했다. 현재 연결된 세션을 관리자가 종료하는 기능도 있다.

접속 대상과 이력을 한 화면에서 볼 수 있다는 점은 좋았다. 사용자마다 원격접속 프로그램을 준비할 필요도 줄어든다.

## 운영까지 가져가지 않은 이유

LDAP 연동에서 불안정한 부분이 있었다. 테스트에서는 다시 확인해 보면 되지만, 실제 운영에서 계정 연동이 흔들리면 접속 자체에 문제가 생긴다. 이 상태로 운영을 시작하기는 어려웠다.

보안과 사용자 관리도 걸렸다. 누가 어떤 서버에 접근할 수 있는지 정하고, 계정이 바뀔 때 권한을 수정하고, 로그와 세션 기록도 관리해야 한다. 사용자가 로그아웃하지 않고 세션을 남겨 두거나 인증 정보를 노출하는 상황도 고려해야 했다.

웹으로 접속을 모으는 편의성은 확인했다. 하지만 당시 테스트한 환경에서는 그 편의성만으로 운영 부담을 감수하기는 어렵다고 판단했다. 기본 기능을 확인한 기록으로 남겨 둔다.
